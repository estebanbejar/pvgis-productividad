# Cómo contribuir

1. Abre un *issue* describiendo la mejora o error.
2. Crea una rama desde `main` (`feature/…` o `fix/…`).
3. Añade pruebas o ejemplos si procede.
4. Asegúrate de que el código y los gráficos se generan sin errores en MATLAB.
5. Abre un Pull Request.

## Estilo
- Comentarios y mensajes de commit en español o inglés, pero claros.
- Nombrado consistente de variables y ficheros.
